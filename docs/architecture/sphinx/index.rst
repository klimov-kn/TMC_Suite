========================
TMC Suite — Архитектура
========================

Эта документация описывает **архитектуру** программного пакета **TMC Suite**:
состав компонентов, их зону ответственности, зависимости между ними, поток данных
между программами и принципы организации сборки.

TMC Suite — научный пакет для электродинамических расчётов планарных структур
(H-поляризация и X-мода), визуализации матриц рассеяния, диаграмм направленности,
временны́х сигналов и распределений поля. Пакет написан на **C++ / MFC / OpenGL**
и собирается под две платформы — **win32** и **win64**.

Пакет построен как **набор самостоятельных программ**, обменивающихся данными через
файлы, и **набор статических библиотек**, которые эти программы переиспользуют.
Единого «монолитного» приложения нет: каждое счётное ядро и каждый вьювер —
отдельный ``.exe``.

Содержимое полностью соответствует Markdown-версии документации
(``docs/architecture/``).
