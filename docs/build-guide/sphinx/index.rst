TMC Suite — Инструкция по сборке
============================================

программ и библиотек **TMC Suite** из исходного кода — отдельно для платформ
**win32** и **win64**.

Содержимое полностью соответствует Markdown-версии инструкции
(``docs/build-guide/``): те же баги, те же правки кода, те же инструменты и версии.
