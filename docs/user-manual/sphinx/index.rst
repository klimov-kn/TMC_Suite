====================================
TMC Suite — Руководство пользователя
====================================

Это руководство пользователя описывает работу с программами пакета **TMC Suite**:
назначение каждой программы, главное окно, панель инструментов, пункты меню и
диалоги — с пошаговыми инструкциями и скриншотами.

Содержимое полностью соответствует Markdown-версии документации
(``docs/user-manual/``).
