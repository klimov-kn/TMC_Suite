# TMC Suite — Документация на программный код (API)

Эта документация описывает программный интерфейс (API) всех библиотек и программ
пакета **TMC Suite**: классы, функции, параметры, возвращаемые значения и ошибки.

Цель — чтобы у программиста, читающего документацию, не осталось вопросов по
устройству и использованию кода.
